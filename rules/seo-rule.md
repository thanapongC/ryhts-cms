# SEO Rule: CMS + Frontend

This document describes how SEO is designed in the i-Stock Express system across Strapi CMS and Astro frontend.

## System Roles

- CMS owns editable SEO content: titles, descriptions, social metadata, crawl directives, canonical input, schema type, keywords, and global tracking IDs.
- Frontend owns SEO rendering: HTML meta tags, canonical URL generation, hreflang links, robots meta format, sitemap, robots.txt, JSON-LD, and fallback defaults.

## CMS SEO Components

### `shared.seo-meta`

Used for page-specific SEO metadata.

Source: `src/components/shared/seo-meta.json`

Fields:

- `metaTitle`: localized string, max `70` characters.
- `metaDescription`: localized text, max `160` characters.
- `ogTitle`: localized Open Graph title override.
- `ogDescription`: localized Open Graph description override.
- `ogImage`: single image media field.
- `ogType`: `website`, `article`, or `product`; default `website`.
- `canonicalUrl`: string field for canonical input.
- `noindex`: boolean; default `false`.
- `nofollow`: boolean; default `false`.
- `noarchive`: boolean; default `false`.
- `nosnippet`: boolean; default `false`.
- `maxSnippet`: integer; default `-1`.
- `maxImagePreview`: `none`, `standard`, or `large`; default `large`.
- `maxVideoPreview`: integer; default `-1`.
- `schemaType`: `WebPage`, `AboutPage`, `ProductPage`, `CollectionPage`, `FAQPage`, `ContactPage`, `Article`, or `SoftwareApplication`; default `WebPage`.
- `keywords`: localized text.
- `alternateLanguages`: JSON.

### `shared.seo-config`

Used for site-wide SEO configuration through Global Settings.

Source: `src/components/shared/seo-config.json`

Fields:

- `siteUrl`: required string.
- `siteName`: required localized string.
- `defaultTitle`: localized string.
- `defaultDescription`: localized text.
- `defaultOgImage`: single image media field.
- `brandName`: localized string.
- `facebookUrl`, `lineUrl`, `linkedinUrl`, `youtubeUrl`: social profile URLs.
- `twitterHandle`: social handle.
- `googleAnalyticsId`: GA4 ID used by the frontend consent-aware analytics loader.
- `facebookPixelId`: Meta Pixel ID used by the frontend consent-aware marketing loader.

## Frontend Metadata Rules

Source files:

- `web/src/layouts/Layout.astro`
- `web/src/lib/seo/metadata.ts`
- `web/src/lib/seo/config.ts`
- `web/src/lib/seo/canonical.ts`

Every public page should render through `Layout.astro`.

Metadata priority:

1. Explicit page props passed to `Layout`.
2. CMS `seo` component values.
3. Frontend defaults from `web/src/lib/seo/config.ts`.

Rendered tags:

- `<title>`
- `meta[name="description"]`
- `meta[name="keywords"]` when keywords exist.
- `meta[name="author"]`
- `meta[name="robots"]`
- canonical `<link rel="canonical">`
- Open Graph tags: `og:type`, `og:url`, `og:title`, `og:description`, `og:image`, `og:image:width`, `og:image:height`, `og:site_name`, `og:locale`
- Article dates when provided: `article:published_time`, `article:modified_time`
- Twitter tags: `twitter:card`, `twitter:url`, `twitter:title`, `twitter:description`, `twitter:image`
- Hreflang alternates for `th`, `en`, and `x-default`

Title formatting:

- `formatTitle()` appends `| iStock Express` unless the title already contains the site name.
- Do not manually duplicate the brand suffix in CMS titles unless a specific title requires it.

Description fallback:

- Thai pages use `seoConfig.defaultDescription`.
- English pages use `seoConfig.defaultDescriptionEn`.

## Canonical And Locale Rules

Canonical URLs are generated by the frontend from normalized route path and locale.

Rules:

- Thai canonical URL has no locale prefix: `https://istockexpress.com/path/`.
- English canonical URL uses `/en`: `https://istockexpress.com/en/path/`.
- `x-default` points to the Thai URL.
- Route paths are normalized to start and end with `/`.
- Locale prefixes are stripped before canonical and hreflang generation.

Important implementation note:

- CMS has a `canonicalUrl` field, but `generateMetadata()` currently always uses the computed frontend canonical URL. Treat CMS canonical as advisory unless the frontend implementation is changed.

## Robots Rules

Robots meta is built from CMS/page SEO flags:

- `noindex=false` renders `index`; `true` renders `noindex`.
- `nofollow=false` renders `follow`; `true` renders `nofollow`.
- `noarchive=true` adds `noarchive`.
- `nosnippet=true` adds `nosnippet` and suppresses max preview directives.
- If snippets are allowed, frontend adds:
  - `max-image-preview:{none|standard|large}`
  - `max-snippet:{number}`
  - `max-video-preview:{number}`

Default crawl behavior is:

```txt
index, follow, max-image-preview:large, max-snippet:-1, max-video-preview:-1
```

## Open Graph Image Rules

Frontend behavior:

- CMS `seo.ogImage` wins when provided.
- Page-level fallback images are used by many route files, for example `/og-home.jpg`, `/og-products.jpg`, `/og-support.jpg`.
- If no page image exists, metadata falls back to `seoConfig.defaultOgImage`.
- Open Graph image dimensions are rendered as `1200x630`.

Generated static OG images live in `web/public/` and are generated by:

```sh
cd web
npm run og:generate
```

Production builds run OG generation automatically through `web/package.json`:

```sh
npm run build
```

## Sitemap Rules

Sitemap source:

- `web/src/pages/sitemap.xml.ts`

Sitemap pages are defined in:

- `web/src/lib/seo/config.ts`

Rules:

- Sitemap includes Thai and English URLs for each `sitePages` entry.
- Thai sitemap URLs currently render with `/th` prefix.
- English sitemap URLs render with `/en` prefix.
- Each URL includes `lastmod`, `changefreq`, `priority`, and hreflang alternates.
- `lastmod` is generated from the current build/request date.
- English priority is `0.1` lower than Thai, with minimum `0.1`.
- Sitemap response cache header is `public, max-age=3600`.

When adding a public route, also add it to `sitePages`.

## Robots.txt Rules

Source:

- `web/public/robots.txt`

Current rules:

- Allow all crawlers by default.
- Disallow `/api/`, `/admin/`, `/dashboard/`, `/account/`, `/login/`, `/register/`, and `/*.json$`.
- Allow `/_astro/` assets.
- Advertise sitemap at `https://istockexpress.com/sitemap.xml`.
- Set crawl delay to `1`.

## Content Authoring Standards

Use these standards when entering SEO content in CMS:

- Write one localized `metaTitle` and `metaDescription` per locale.
- Keep `metaTitle` under `70` characters.
- Keep `metaDescription` under `160` characters.
- Prefer a clear product or page keyword near the start of the title.
- Do not keyword-stuff `keywords`; this field is optional.
- Use `ogTitle` and `ogDescription` only when social copy should differ from search copy.
- Use a `1200x630` image for `ogImage`.
- Use `noindex` only for pages that should not appear in search.
- Use `nofollow` only when links on the page should not pass crawl signals.
- Keep slug changes rare after publication; changing slug requires redirect handling outside this SEO layer.
- Publish only one canonical version of each page per locale.

## Known Gaps To Keep In Mind

- `shared.seo-config` is modeled in CMS, but frontend defaults such as `siteUrl`, `siteName`, brand name, default descriptions, phone, and email are currently hard-coded in `web/src/lib/seo/config.ts`.
- CMS `canonicalUrl` is modeled, but frontend canonical output is computed and does not currently use CMS canonical overrides.
- `schemaType` is modeled in CMS, but page JSON-LD is selected by frontend route/component logic.
- Sitemap Thai URLs use `/th`, while canonical Thai URLs omit the locale prefix. Review this before launch if strict canonical/sitemap alignment is required.
